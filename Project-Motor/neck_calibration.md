# Neck 标定记录

> 标定日期：2026-08-15　单位：全部为度（电机为减速器输出轴角）
> 相关文件：机构说明见 `neck_model.md §4` 与 `neck.jpg`；参数落地在 `neck_config.txt`；重标工具 `tools/neck_calibrate.py`；逆解实现 `neck_kinematics.h`。

## 1. 机构

2 自由度并联倾摆 + 串联偏航：

- 1 号电机(左)、2 号电机(右)经曲柄-连杆并联驱动，共同产生 **pitch/roll**（镜像耦合，pitch 为差动、roll 为同向）。
- 3 号电机装在倾摆平台上，**1:1 直驱**头部 **yaw**（已确认 `k3=1`）。

## 2. 实测原始数据

中位（头部水平、正前方）电机角：`m0 = (m10, m20, m30) = (10, 26, 177)`。

纯 pitch（roll=0）：

| 头部 pitch | m1 | m2 |
|---|---|---|
| +25°（最大后仰/抬头） | 55 | −33 |
| 0°（水平） | 10 | 26 |
| −40°（最大前倾/低头） | −85 | 113 |

纯 roll（pitch=0，两向极限约 ±35°；**方向符号为假设，待实机确认**）：

| 头部 roll | m1 | m2 |
|---|---|---|
| −35°（假设） | −65 | −12 |
| +35°（假设） | 54 | 95 |

yaw / 3 号电机：范围 60° 至 235°，中位 177°；1:1 直驱 → yaw 范围 −117° 至 +58°。

连杆长约 55cm（线性标定未用到，仅解析建模才需要，数值待核）。

## 3. 推导方法

逐轴用过中位的割线（正反两向取平均）得逆运动学雅可比 `A`（电机=A·头部），再取逆得 `C`（头部=C·电机）：

```
a11=mean(Δm1/p)=2.087   a12=mean(Δm1/r)=1.700
a21=mean(Δm2/p)=-2.268  a22=mean(Δm2/r)=1.529
C = A^{-1}
```

## 4. 标定结果（已写入 neck_config.txt）

```
c11 = 0.2170   c12 = -0.2413
c21 = 0.3218   c22 = 0.2963      det(C) = 0.1419
k3  = 1.0
m0  = (10.0, 26.0, 177.0)
限位: m1[-85,64] m2[-34,113] m3[60,235] | pitch[-40,25] roll[±35] yaw[-117,58]
```

对称性校核通过：`c11≈−c12`、`c21≈c22`，符合镜像耦合结构。

## 5. 精度与已知限制（后续微调入口）

- **线性 = 中位附近的局部近似**。用大角度极限数据拟合，实测残差在极限处最大 ~7°（如满 roll 会带出约 7° 寄生 pitch）。中位附近准确。
- **满程 −40° 低头** 线性外推 m2→116.7° > 限位 113°，会被 `neckSolve` 保守拦截。要走满程：把 `motor2_max` 放宽到 ~118，或改分段/非线性标定。
- **roll 正方向** 为假设。实机 `NeckPoseSet 0 0 10 0` 若不是向右侧头，则将 `c21,c22` 取负。
- **pitch/yaw 方向** 若与约定相反，分别重标 pitch 或令 `k3=-1`。

### 如何做更精确的数值调整
1. 想提升**中位附近精度**：用 ±10° 小角度重新采集三轴，重跑 `python3 tools/neck_calibrate.py`（局部线性更贴合）。
2. 想覆盖**大角度**：分区间(如低头/抬头/中位)各标一组 `C`，或改非线性/查表模型（见 `neck_model.md §8` 末尾）。
3. 只改数值不动代码：直接编辑 `neck_config.txt`，无需重新编译。

## 6. 实机复核记录（2026-08-20，受控低速验证）

方法：`NeckCalibMove`（单轴 ±2°，标定档限速 10°/s、幅度上限 5°、CALIBRATION 状态、
反馈/跟踪/急停保护）与 `NeckCalibPose`（三轴联动）。全程急停旁有人值守，物理急停实测有效。

**方向约定全部验证通过（含此前标记为"假设"的 roll 方向）**：
- m3 +2° → 头向左转 ~2°（yaw 约定确认，k3=1 直驱）；
- m1 +2° → 微抬头 + 向右倾（c11/c21 符号确认）；
- m2 +2° → 微低头 + 向右倾（c12/c22 符号确认）。
→ 无需修改 `calib.axis_sign`。

**数据记录**：
- 单轴运动无串扰（动 m3 时 m1/m2 读数不变，反之亦然）；
- 稳态跟踪误差 ~0.001°（S 曲线结束瞬间有 ~0.07° 收敛暂态，数秒内收敛）；
- 保持期间 yaw 轴有小幅下垂：首次收敛暂态 ~0.2°，随后有界（~0.01°/min 量级）；
- m3 往返净位移 +0.14°（回差 + 下垂量级 ~0.1°）；
- 温度 27~28°C，保持电流 ~0.05A，无异常声音/振动；
- 急停首次实机验证：按下断动力、位置无位移、恢复使能无跳变。

**结论**：C/k3/m0 方向约定可信；速度/加速度/jerk 上限仍为保守占位，需按阶梯继续验证后确认。
