# Neck 头部姿态逆解数学模型

## 1. 目标

本模型只负责一个中间步骤：

```text
头部目标姿态（抬头低头、侧头、左右转头）
                    ↓
              数学逆解模型
                    ↓
三个电机的目标旋转角度
```

模型不处理电机通信、速度控制、力矩控制、轨迹规划和头部位置控制。

> 单位约定（全链路统一为**度**）：头部姿态 pitch/roll/yaw、电机输出轴角、配置文件、CLI 输入输出都用度。底层 `set_motor_position` 接收的就是减速器输出轴角度(度)，因此不再做弧度↔度转换，`C`、`k3` 为无量纲比值（头部度 / 电机度）。

## 2. 输入和输出

输入使用相对于机械中位的三个角度，单位统一为度：

```text
p：pitch，抬头/低头角度
r：roll，向左/向右侧头角度
y：yaw，头部向左/向右旋转角度
```

输出为三个电机的目标角度：

```text
m1：第一号基座电机目标角度
m2：第二号基座电机目标角度
m3：第三号电机目标角度
```

本项目底层 `set_motor_position` 使用的就是**减速器输出轴角度**，因此所有参数直接按输出轴标定，无需再并入减速比。

> 机构补充：一号、二号电机镜像耦合共同产生 pitch/roll，三号电机产生 yaw。`neck_kinematics.h` 里的 `MOTORx_START_DEG` 是**上电/静止的最低位**（电机 1 在其最小角、电机 2 在其最大角、电机 3 居中），**不是头部中位**。头部正中（pitch=roll=yaw=0）对应的电机角 `m0=[m10,m20,m30]` 必须在标定时单独记录（见 §8）。

## 3. 正方向和零位

建议采用以下方向：

- `p > 0`：抬头，`p < 0`：低头；
- `r > 0`：向右侧头，`r < 0`：向左侧头；
- `y > 0`：向左转头，`y < 0`：向右转头；
- `p = r = y = 0`：机械中位。

如果实物的正方向相反，不要在控制程序中到处手动取负号，只在下面的标定参数中保留负传动比。

## 4. 机构自由度和电机分工

实物为 **2 自由度并联倾摆 + 串联偏航** 机构（见 `neck.jpg`）：

```text
电机 1 + 电机 2  → 共同产生 pitch 和 roll（并联双曲柄-连杆驱动万向节平台）
电机 3           → 产生 yaw
```

- **1 号电机(左)、2 号电机(右)** 装在底座上，轴水平朝前，各带一个**曲柄盘**；盘上偏心销接一根**两端球头(杆端轴承)的连杆**竖直上推。
- 两根连杆顶端连到**上方倾摆平台**，平台中央经一个**被动 2 自由度万向/十字铰**与底座相连，此铰即倾摆旋转中心。
- 两杆**协同/差动**推拉平台，共同决定平台的 pitch 与 roll：两电机同向→前后倾(pitch)，差动→左右倾(roll)。因此 1、2 号电机不是各自对应 pitch/roll，而是一个**耦合二维传动**。
- **3 号电机** 装在倾摆平台上，轴竖直，提供 yaw；头部安装在其输出端。

结构含义：

- **符号/对称结构**：左右镜像安装（2 号"最低位"= 其编码器最大角），对同一物理 pitch，`Δm1` 与 `Δm2` 编码器符号相反。故 C 近似满足 `c11≈−c12`、`c21≈c22`（或其镜像），可用于校核标定结果。
- **本质非线性**：曲柄-连杆 + 万向节使真实映射非线性，第 5 节的线性 `C`/`k3` 只是**中位附近的局部雅可比**；小角度准确，大角度需按第 8 节改分段查表或非线性标定。

## 5. 电机角度到头部角度

定义电机中位角度：

```text
m0 = [m10, m20, m30]ᵀ
```

定义电机相对中位的变化量：

```text
Δm = [m1 - m10, m2 - m20, m3 - m30]ᵀ
```

定义头部相对中位的姿态向量：

```text
q = [p, r, y]ᵀ
q0 = [p0, r0, y0]ᵀ
```

线性标定模型为：

```text
p - p0 = c11·Δm1 + c12·Δm2
r - r0 = c21·Δm1 + c22·Δm2
y - y0 = k3·Δm3
```

矩阵形式为：

```text
[p]     [p0]     [c11  c12  0 ] [Δm1]
[r]  =  [r0]  +  [c21  c22  0 ] [Δm2]
[y]     [y0]     [ 0    0   k3] [Δm3]
```

其中：

- `c11、c12、c21、c22`：一、二号电机到 pitch/roll 的耦合传动比；
- `k3`：三号电机到 yaw 的传动比；
- 传动比单位为“头部弧度 / 电机弧度”；
- 参数正负号表示实际旋转方向。

## 6. 目标姿态到三个电机角度

给定目标姿态：

```text
q_target = [p_target, r_target, y_target]ᵀ
```

令：

```text
Δp = p_target - p0
Δr = r_target - r0
Δy = y_target - y0
```

二维耦合矩阵为：

```text
C = [c11  c12]
    [c21  c22]
```

行列式为：

```text
det(C) = c11·c22 - c12·c21
```

当 `det(C)` 不为零时，三个电机目标角度为：

```text
Δm1 = ( c22·Δp - c12·Δr ) / det(C)
Δm2 = (-c21·Δp + c11·Δr ) / det(C)
Δm3 = Δy / k3
```

最后：

```text
m1_target = m10 + Δm1
m2_target = m20 + Δm2
m3_target = m30 + Δm3
```

这就是后续程序需要执行的唯一中间算法。

## 6.5 可达性与限位判定

逆解在下发前必须通过以下检查（对应 `neck_kinematics.h` 的 `neckSolve` 与 `enum NeckStatus`）。任一不通过则判定目标不可达，不发送电机命令：

```text
1. 奇异判定：  |det(C)| < det_eps  或  |k3| < det_eps        → SINGULAR
2. 姿态限位：  pitch/roll/yaw 超出 [*_min, *_max]            → POSE_OUT_OF_RANGE
3. 电机限位：  逆解出的 m1/m2/m3 超出 [motorX_min, motorX_max] → MOTOR_OUT_OF_RANGE
```

所有阈值与限位存放在配置文件 `neck_config.txt`（`NeckConfig`），改参数无需重新编译。

## 7. 旋转组合约定

如果需要将三个角度表示成完整的头部姿态矩阵，采用以下约定：

```text
R_target = Rz(y) · Rx(p) · Ry(r)
```

坐标系定义为：`+Y` 从颈部指向头部前方，`+X` 为横向右侧，`+Z` 向上。这里采用的是“先 yaw，再 pitch，最后 roll”的局部连续旋转约定。控制范围较大时应限制 pitch，避免欧拉角奇异；如果以后需要覆盖大角度范围，应改用四元数作为上层姿态表示。

## 8. 实机标定步骤（可执行）

STL/STEP 只有静态姿态，不能可靠提供传动比、编码器零点、回差和正方向，因此以下参数必须实测。采集用现有 CLI：`MotorPositionSet` 转单个电机、`MotorAngleGet` 读回电机输出轴角(度)，头部角用量角器/手机 APP 测量(度)。全部单位为度。

1. **记录中位**：将机构摆到头部正中（目视 pitch=roll=yaw=0），用 `MotorAngleGet` 记录 `m10、m20、m30`，令 `p0=r0=y0=0`。
2. **标定电机 1**（仅动电机 1）：正向转一个角度，记录 `Δm1` 与头部 `Δp、Δr`；反向再测一次。得到 `c11=Δp/Δm1`、`c21=Δr/Δm1`（正反取平均）。
3. **标定电机 2**（仅动电机 2）：同法得到 `c12=Δp/Δm2`、`c22=Δr/Δm2`。
4. **标定电机 3**（仅动电机 3）：`k3 = Δy/Δm3`（正反取平均）。
5. **回差**：每轴正、反方向各测并取平均，减小连杆回差影响。
6. **限位**：测量每个电机与头部姿态的安全范围，填入 `neck_config.txt`；逆解后由 `neckSolve` 自动检查。

推荐直接用交互式脚本完成上述采集与计算，它会把结果写进 `neck_config.txt`：

```bash
python3 tools/neck_calibrate.py
```

校核：标定后对若干已知姿态调用 `NeckPoseSet`，用 `MotorAngleGet` 读回电机角与逆解值比对；下发 `NeckPoseSet <slave> 0 0 0` 应回到 `m0`。如果不同姿态误差明显变大，说明线性模型不足，应将 `C`、`k3` 扩展为分段查表或非线性标定。

## 9. 最终接口定义

最终算法可以固定为：

```text
输入：  pitch_target, roll_target, yaw_target
输出：  motor1_target, motor2_target, motor3_target
```

其中：

```text
motor1_target = m10 + ( c22·Δp - c12·Δr ) / det(C)
motor2_target = m20 + (-c21·Δp + c11·Δr ) / det(C)
motor3_target = m30 + Δy / k3
```

如果 `det(C)` 接近零，或者任一输出超过安全范围，算法应判定目标姿态不可达，不应直接发送电机命令。
